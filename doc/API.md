# Cerqle Flutter SDK API Contract

This document describes the Flutter API implemented by this package and
the Cerqle visitor API it interfaces with.

## Public Flutter entry points

```dart
final config = CerqleConfig(widgetKey: 'YOUR_WIDGET_KEY');
await CerqleChat.open(context, config: config);
```

Supported presentation styles are `CerqleChatScreen`,
`CerqleChatLauncher`, `CerqleChatView`, `CerqleChat.open(...)`, and a
headless `CerqleChatController`.

The controller supports:

```dart
Future<void> initialize();
Future<void> refresh();
Future<CerqleMessage> sendText(String text);
Future<CerqleMessage> sendImage(CerqleUpload upload, {String? caption});
Future<CerqleMessage> sendAudio(CerqleUpload upload, {String? caption});
Future<void> setTyping(bool isTyping);
Future<void> requestHumanAgent();
Future<void> submitPreChat(CerqlePreChatData data);
Future<void> updateUser(CerqleUser? user);
Future<void> resetSession();
Future<void> dispose();
```

Passing `null` to `updateUser` is the host-application logout operation. It
stops polling and realtime streaming, sends typing `false` on a best-effort basis,
unlinks OneSignal device tags, deletes the active identity-scoped visitor ID/token,
clears in-memory messages, and returns the controller to `idle`. A later `initialize()`
creates a fresh anonymous session.

## Identity and session storage

`CerqleUser` maps directly to the session payload:

| Dart | JSON |
|---|---|
| `name` | `name` |
| `email` | `email` |
| `avatarUrl` | `avatar` |
| `externalId` | `external_id` |
| `signature` | `user_hash` |

Signatures are HMAC-SHA256 values generated by the integrating company's
server with the widget identity secret. The secret must never enter a Flutter
application.

The encrypted visitor token is the authority for one conversation. The default
store keeps the matching visitor ID and token together in secure storage under
a base-URL, widget-key, and identity-scoped namespace.

## Push Notifications & Realtime Pusher Streaming

The SDK automatically retrieves the OneSignal push token (`currentPushToken()`)
and attaches `device_id`, `onesignal_id`, and `push: {token: ...}` to session requests.
Pusher WebSocket channels (`private-widget-conversation.{conversationId}`) deliver
live message and typing updates.
