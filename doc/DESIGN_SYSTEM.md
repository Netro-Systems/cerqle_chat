# Cerqle Design System

## Signature Color Palette

- Primary: `#3E2A49` (Deep Cerqle Purple)
- Secondary: `#8F5FA7` (Soft Lilac Accent)
- Surface: `#FFFFFF` (Clean White)
- Background: `#F8FAFC` (Slate Tint Background)
- Border: `#CBD5E1` (Subtle Slate Border)
- Text Primary: `#1E293B`
- Text Muted: `#64748B`

## Typography and Components

- Cards with rounded radii (12-16px) and subtle slate borders.
- Floating launcher button styled with primary brand color.
- Responsive message bubbles with distinct visitor vs agent roles.
- Smooth typing indicators and shimmering placeholder states.
